## Sobre o projeto

O `CodeSpace Lab` é um espaço de experimentação: um projeto simples, aberto e pronto para receber novas ideias.

Aqui, o objetivo não é entregar um produto final, mas **aprender fazendo**, testar possibilidades e observar como uma aplicação pode nascer, evoluir e ser executada diretamente na nuvem com o GitHub Codespaces.

## O que este laboratório explora

- **Desenvolvimento na nuvem:** um ambiente completo acessível pelo navegador.
- **Next.js:** uma base moderna para construir aplicações web.
- **Iteração rápida:** editar, executar e validar ideias em poucos segundos.
- **Boas práticas:** organização, versionamento e evolução contínua do projeto.

## Começando

### Pré-requisitos

- Node.js instalado
- npm disponível no terminal
- Ou um ambiente aberto no **GitHub Codespaces**

### Instalação

```bash
npm install
```

### Desenvolvimento

```bash
npm run dev
```

Depois, abra [http://localhost:3000](http://localhost:3000) para visualizar a página de testes.

## Estrutura atual

```text
app/
├── layout.js   # Layout raiz e metadados
└── page.js     # Página inicial do laboratório
```

## Próximos experimentos

Este laboratório pode crescer conforme as ideias aparecem: novos componentes, estilos, rotas, integrações e qualquer experimento que ajude a transformar curiosidade em código.

> **A regra é simples:** experimentar, observar, melhorar e repetir.
